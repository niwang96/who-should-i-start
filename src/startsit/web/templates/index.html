How it works

Code gathers the evidence for each player: the FantasyPros expert consensus, recent usage (snaps, targets, expected points), betting lines, the injury report and this week's news. It computes a baseline pick from the consensus projection. An AI then makes the call, citing the numbered evidence it used, and must explain itself if it disagrees with the baseline. It may only use the listed facts. If the AI is busy or unavailable, you get the baseline pick.

Expert consensus rankings and projections: FantasyPros. Stats, snaps, injuries, schedules and betting lines: nflverse. News: RotoWire, ProFootballTalk and CBS Sports (linked with each item). AI: Google Gemini.
